
# 🐸 Ninja Frutal:
*🌟 Descripción del Proyecto*

Ninja Frutal es un emocionante juego de plataformas 2D que combina la acción rápida con la recolección estratégica. El jugador asume el papel de una rana ninja ágil y habilidosa, cuyo único objetivo es aventurarse a través de diversos niveles para recolectar las codiciadas manzanas .

El juego se centra en la precisión de los saltos y el timing para esquivar obstáculos y enemigos, ofreciendo una experiencia divertida y desafiante. Este proyecto sirve como una excelente demostración del desarrollo de juegos de plataformas utilizando las capacidades estándar del motor Unity.


*⚙️ Tecnologías y Requisitos*

Este proyecto ha sido desarrollado íntegramente dentro del ecosistema de Unity, utilizando C# para toda la lógica del juego.

Requisitos del sistema
Para abrir y trabajar con el código fuente del proyecto, necesitarás:

**Motor de juego**: Unity 6 (6000.2.6f1) o Unity 6.0 (6000.0.58f1) LTS .

**Idioma de programación**: C# (Se incluye automáticamente con la instalación de Unity).

**IDE (Entorno de Desarrollo Integrado)**: Visual Studio es el recomendado para editar y depurar los scripts de C#.
